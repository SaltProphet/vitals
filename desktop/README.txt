Vitals 1.1.0 for Windows
========================

A portable live utilization monitor for THIS PC: CPU (per core), memory,
disk, network, process tree (name, PID, CPU, memory), uptime, and thermal
when Windows exposes a sensor.

Nothing is installed. Nothing is sent off this machine.

How to run
----------
1. Unzip this folder anywhere.
2. Double-click Vitals.exe.
3. Your default browser opens the dashboard. Leave Vitals.exe running
   while you watch the gauges.

If Windows says "Windows protected your PC"
-------------------------------------------
This build is not code-signed. Choose More info → Run anyway.

Quit
----
Use "Quit Vitals" in the dashboard, or end Vitals.exe in Task Manager.

Spin cores
----------
Exercises every logical processor for 8 seconds so you can see CPU
and load respond on this PC.

Requirements
------------
Windows 10 or 11, 64-bit. No extra runtime.

Integrity
---------
See SHA256.txt in this folder.
